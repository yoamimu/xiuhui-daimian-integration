# 绣绘授权验证隐私说明

绣绘的授权系统仅处理完成软件授权所必需的信息：

- 用户输入的激活码；服务器只保存其带服务端密钥的 HMAC-SHA256 摘要。
- 由 Mac 硬件 UUID 在本机单向哈希生成的设备密钥；服务器不接收原始硬件 UUID。
- Mac 型号、macOS 版本、处理器架构和绣绘版本，用于识别绑定设备及排查兼容问题。
- 激活、最后验证、解绑和后台管理操作时间。

这些信息只用于确认授权有效期、限制设备数量、处理换机解绑和排查授权故障，不用于广告或跨应用追踪。授权记录按销售与售后需要保留；管理员可以停用授权和解绑设备。

客户端通过 HTTPS 与授权服务器通信。应用每次启动都会尝试在线验证；服务器不可用时，可在服务器最近签发的短期离线许可有效期内继续使用。设备密钥和授权令牌存放在 macOS Keychain 中。
