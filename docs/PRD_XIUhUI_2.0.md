# 绣绘 2.0 产品需求文档（PRD）

版本：v0.1  |  状态：规划中  |  更新：2026-08-30

## 1. 产品定位

绣绘 2.0 是面向刺绣制版用户的图案处理、针法编辑、质量检查、仿真预览和机器文件导出软件。产品继续以 Inkscape 与 Ink/Stitch 为技术底座，重点把现有分散能力整理成完整的刺绣工作流：

> 导入图案 → 处理图像 → 生成刺绣对象 → 调整针法 → 检查质量 → 仿真预览 → 导出生产文件

## 2. 产品目标

- 降低从图片到可上机刺绣文件的学习成本。
- 把 Inkscape 的矢量编辑能力与 Ink/Stitch 的针法、预览和导出能力连接起来。
- 在导出前发现密度、跳针、换色、超框和起止点问题。
- 提供面向普通用户的刺绣工作区，同时保留专业矢量编辑能力。
- 继续支持 Windows、macOS Apple Silicon 和 macOS Intel。

### 非目标

- 不从零重写 SVG 编辑器或刺绣引擎。
- 不承诺任意照片可以一键生成无需人工检查的生产文件。
- 不直接删除所有 Inkscape 底层功能，优先隐藏入口并提供高级模式。
- 不把 Inkscape/Ink-Stitch 的 GPL 代码包装成禁止修改或再分发的闭源组件。

## 3. 目标用户与场景

### 用户

- 刺绣初学者：需要向导、预设和易懂的错误提示。
- 家庭或工作室制版人员：需要快速处理图片、调整针法和导出。
- 服装、帽子、毛巾、徽章生产者：需要绣框、换色和生产检查。
- 熟悉 Inkscape 的专业用户：需要节点、路径和高级矢量能力。

### 典型场景

1. 导入 JPG、PNG、扫描图或 AI 生成图。
2. 去背景、减色、提取线稿并清理杂点。
3. 将色块和轮廓转换为刺绣对象。
4. 设置针法、针距、填充方向、补偿和对象顺序。
5. 播放针迹预览，检查质量后导出 DST 等机器文件。

## 4. 产品工作区

### 绣绘模式（默认）

显示：新建项目、导入、图片处理、刺绣对象、针法参数、绣框、线色、仿真、质量检查和导出。使用任务导向按钮和刺绣术语。

### 高级矢量模式

保留 Inkscape 的节点、路径、图层、文本、填充和描边工具，供复杂图形清理和专业用户使用。两个模式共用同一文档和对象数据。

## 5. P0 核心需求

### 5.1 刺绣制版向导

新建项目时选择：绣框尺寸、方向、目标机器格式、面料类型、线材/线卡（可选）和图案最终尺寸。根据选择加载安全的默认参数，用户可以继续修改。

### 5.2 图片导入与预处理

针对 JPG、PNG、扫描图和 AI 生成图提供可预览、可撤销的处理步骤：

- 自动去背景和前景提取。
- 自动抠图。
- 颜色数量压缩。
- 相近颜色合并。
- 线稿提取。
- 阈值黑白化。
- 前景与背景分离。
- 自动识别封闭区域。
- 删除小杂点和孤立区域。
- 原图保留在独立图层，不覆盖原始素材。

说明：Inkscape 已有“位图描摹”等基础能力，但主要输出普通 SVG 路径；绣绘需要继续把结果连接到刺绣对象和针法流程。

### 5.3 刺绣对象编辑器

支持走针、平针、填充针、缎面针、贴布和包边。用户可以修改针距、密度、填充角度、下布针、补偿、起点、终点、走针方向、锁针、剪线、跳针、对象顺序和颜色顺序，并能合并、拆分、复制、隐藏和锁定对象。

### 5.4 绣框与排版

- 显示真实绣框边界和安全边距。
- 实时提示超出绣框。
- 支持绣框预设、旋转、缩放、居中和对齐。
- 为大图案提供分片规划基础，后续增加定位点和拼接辅助线。

### 5.5 刺绣仿真预览

按针迹或颜色播放，支持暂停、继续、逐针和调速；显示当前针位置、针数、颜色变化、跳针、剪线、预计制作时间，并支持正面/反面预览和密度热力图。

### 5.6 质量检查

导出前分级显示错误、警告和建议，并可跳转到对应对象：针距过小、密度过高、线段过短、跳针过长、缺少下布针/锁针、起止点不合理、对象顺序不佳、颜色变化过多、图案超框、区域小于可绣尺寸，以及可能导致鼓包、断线、布料变形或底线外露的问题。

### 5.7 导出检查

显示目标格式、总针数、颜色数、换色清单、跳针/剪线统计、最大连续线段、绣框占用和未处理问题。首批重点保障 DST，后续评估 PES、JEF、EXP、VP3 和 XXX。

### 5.8 稳定性与数据安全

- 自动保存和崩溃恢复。
- 导入/导出进度和可理解的失败原因。
- 插件异常不损坏主文档。
- 授权过期仍可打开、查看和保存已有设计，并能查看设备码和续费。
- 大图、高针数、多图层文件显示资源占用或处理进度。

## 6. P1 功能

### 6.1 文字与字母

刺绣字体、单线字体、中英文混排、字距/行距、弧形文字、圆形排字、小字号可绣性提示，以及中文姓名、胸牌和校服模板。

### 6.2 徽章与布贴

圆形、盾形、圆角矩形模板；自动外轮廓、包边、贴布层、E-stitch、缎面边、走针边和定位层。

### 6.3 线色管理

常见线卡和线号、相近颜色匹配、品牌转换、线色统计、换线清单和打印版颜色表。

### 6.4 多绣框与分片

超框检测、自动/半自动分片、定位点、拼接辅助线和拼接误差提示。

## 7. P2 功能

- 批量改尺寸和批量导出。
- 订单、客户和设计管理。
- 生产参数模板。
- 更多机器格式和机型预设。
- 云端备份或团队协作（需单独评估隐私和成本）。

## 8. 界面调整原则

绣绘模式优先隐藏开发调试、实验性 SVG、网页/动画和低频格式入口；不急于删除底层代码。选择、移动、缩放、节点、路径、图层、对象、文本、图片导入、SVG 兼容、撤销/重做和 Ink/Stitch 扩展接口必须保留。

## 9. 技术原则

- 当前基线继续使用 Inkscape `7923d92` 和 Ink/Stitch `0312dac`，升级另行评估。
- 复用 Ink/Stitch 针法、预览和导出能力，绣绘负责流程、预设、检查和体验。
- 图片处理优先支持离线运行，设计图默认不上传云端。
- Windows、macOS 和不同芯片必须分别回归测试。
- 每次功能、构建或客户包变化都更新 `docs/PROJECT_LOG.md`。
- 发布时继续提供 Inkscape/Ink-Stitch 版权、许可证、来源和对应源码说明。

## 10. 验收标准

- 用户可以从 JPG/PNG 开始完成导入、处理、制版、检查、预览和导出流程。
- 原图不被覆盖，处理步骤可以撤销。
- 至少支持走针、填充和缎面等主要对象编辑。
- 仿真显示针迹、换色、跳针和剪线。
- 导出前可以定位主要质量问题。
- DST 导出通过回读或基本结构检查。
- Apple Silicon、Intel 和 Windows 目标环境稳定。
- 正常绘制不崩溃、不闪烁。
- 授权流程不会损坏设计文件，新设备可以进入激活流程。

## 11. 版本路线

### 2.0.0：制版工作流

绣绘模式/高级矢量模式、制版向导、图片预处理、刺绣对象编辑器、绣框排版、仿真预览、质量检查、自动保存和恢复。

### 2.1：文字、徽章与布贴

中文/英文刺绣字体、姓名模板、弧形文字、徽章、布贴、包边和定位层。

### 2.2：生产管理

线卡和颜色管理、多绣框分片、更多机器格式、批量导出、生产清单和订单关联。

## 12. 风险与对策

| 风险 | 对策 |
|---|---|
| 上游更新导致补丁失效 | 固定基线、独立补丁、升级前做回归 |
| 任意图片无法自动得到高质量结果 | 自动处理 + 人工可编辑 + 质量检查，不承诺无人值守 |
| macOS 图形栈差异 | 保持已验证的 Cairo/画布刷新方案，分别回归 |
| 隐藏过多限制专业用户 | 提供高级矢量模式 |
| GPL 合规风险 | 保留许可证/来源并提供对应源码和构建说明 |
| 授权影响文件可用性 | 授权只控制使用期限，不阻断打开、保存和续费 |
